# Publicación del sitio

- Después de validar cualquier cambio solicitado en el sitio, publicarlo en el repositorio GitHub `estudioideamos/ideamos-internacional`.
- La entrega no termina al subir una rama o crear un pull request: el cambio debe quedar integrado en `main` y desplegado por GitHub Pages.
- Esperar a que finalice correctamente el workflow `Deploy to GitHub Pages`.
- Entregar siempre el enlace directo de previsualización correspondiente bajo `https://estudioideamos.github.io/ideamos-internacional/`.
- No publicar en OpenAI Sites salvo que el usuario lo pida explícitamente.
